# Roadmap

## Что сделано

- Собран и размечен датасет — 3876 записей (weak 1288, negative 1584, junk 1004).
- Обучен классификатор weak / negative / junk (accuracy 0.80, F1 macro 0.80 на test).
- Реализован live-сбор данных из 21 источника.
- Реализованы API-эндпоинты: /api/search, /api/insight, /api/stats.
- Реализована группировка результатов по технологии.
- Реализовано кэширование результатов скоринга в scored_documents.

## В работе / планируется

- Подключение патентных источников (Роспатент, USPTO, EPO).
- Расширение датасета.
- Поддержка дополнительных языков.
- Улучшение интерпретируемости (SHAP-визуализация в интерфейсе).
- Мониторинг деградации качества классификатора.

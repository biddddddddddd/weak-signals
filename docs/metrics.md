# Метрики классификатора слабых сигналов

## Архитектура

- **Модель:** Logistic Regression (multinomial, `class_weight='balanced'`, C=0.3)
- **Признаки:** эмбеддинги `paraphrase-multilingual-MiniLM-L12-v2` (384 числа)
- **Классы:** `weak` (слабый сигнал), `negative` (зрелая технология), `junk` (мусор)
- **Датасет:** 3876 примеров
  - weak: 1288
  - negative: 1584
  - junk: 1004
- **Разбиение:** 70% train (2712), 15% val (582), 15% test (582), stratified

## Интерпретируемость

Logistic Regression даёт **веса признаков** (384 веса на класс). Это позволяет показать, какие компоненты эмбеддинга вносят вклад в решение. Для более глубокой интерпретации используется SHAP (`shap.LinearExplainer`).

Основные источники ошибок (test):
- 27 negative → weak: зрелые технологии похожи на слабые сигналы.
- 21 negative → junk: зрелая технология с размытым описанием.
- 19 weak → negative: слабый сигнал похож на зрелый тренд.
- 17 weak → junk: слабый сигнал с низкой конкретностью.
- 19 junk → negative: мусор, маскирующийся под зрелую технологию.
- 11 junk → weak: мусор с научным языком.

# Сценарий демонстрации

## Что показывать жюри

1. Ввод запроса в реальном времени — SearchPage, тематический запрос («нейроморфные вычисления»).

2. Формирование ТОП-15 — итоговый список сигналов.

3. Детализация по каждому сигналу (InsightPage):
   - преимущество,
   - кейс,
   - источник,
   - объяснение.

4. Логика исключения зрелых трендов, хайпа и шума:
   - классификатор → negative,
   - псевдонаучный текст → junk,
   - GigaChat отклоняет кандидата.

5. Проверка источников:
   - наименование,
   - ссылка (URL),
   - дата,
   - тип,
   - язык,
   - trust_level.

## Рекомендуемый порядок

1. StatsPage — масштаб.
2. SearchPage — живой запрос.
3. ТОП-15 → 2–3 карточки.
4. InsightPage — детализация.
5. Пример отсева junk/negative.
6. Метрики классификатора.
